Provider/FCM acceptance and `NotificationManager.notify` are **not** proof of lock-screen display. Samsung never gave the card airtime.

## Root cause

`LiveTripOngoingNotification.ensureChannel` created `onecab_live_trip_v1` at `IMPORTANCE_LOW` (silent ETA ticks). On Android 16 Live Update promotion was denied (`mIsPromotion=false`). Low-importance ProgressStyle ongoing then stayed invisible (`airtime=0`).

MK-261116-007 failed earlier because fanout flags were off. **010 is a different failure:** fanout worked; **visibility channel importance** did not.

## Fix

1. OTA: `ensureLiveTripAndroidNotificationChannel` deletes LOW v1 and recreates at `IMPORTANCE_DEFAULT` + PUBLIC lock-screen (Android forbids raising importance in place).
2. Native (next binary): same recreate logic in `ensureChannel` + notify diagnostic logs.
3. No APNs / credential rotation. No EAS cloud rebuild in this pass — OTA unblocks store **46** fleet.
